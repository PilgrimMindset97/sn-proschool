# Onglet Enregistrer un enseignant

Dans Notes et moyennes > Saisie des notes > Enseignants, matières et classes, deux onglets sont disponibles :
- Liste des enseignants : affiche nom, cycle, matière, classe et salle.
- Enregistrer un enseignant : formulaire dédié avec nom complet, cycle, classe/niveau filtrée par cycle, matière proposée selon la classe et salle de cours.

## Supabase
Exécuter `supabase/migrations/20261030_teachers_cycle_salle.sql` dans l'éditeur SQL du projet Supabase avant d'utiliser l'enregistrement connecté. En mode local, les données restent dans le stockage local du navigateur.
